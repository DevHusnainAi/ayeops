03 · The gate

A code alone never authorizes.

The operator must say the action, the service and the code together. Reading two words off a screen is not the same as understanding the change.

Blind

The code never enters the model’s context.

Voiced

A human proves comprehension out loud.

Refuses

Declines a fix it knows will not hold, and says why.

Logged

Recording, turn timeline and postmortem per authorization.
